# Prompt tersimpan — Penyelamatan source code (disimpan 1 Nov 2026 atas permintaan user)

"Saya ingin menyelamatkan seluruh source code proyek ini sebelum kredit atau akses workspace habis.
Kerjakan langsung apa yang bisa dilakukan dengan akses yang tersedia.
1. Kumpulkan kode: Periksa seluruh source code dan file konfigurasi yang benar-benar ada. Pertahankan struktur folder dan nama file aslinya.
2. Buat file ZIP: Kemas seluruh source code dan file penting yang diperlukan untuk melanjutkan pengembangan ke dalam project-backup.zip. Jangan sertakan node_modules, cache, atau kredensial rahasia.
3. Siapkan rangkuman: Buat PROJECT_CONTEXT.md berisi fungsi aplikasi, teknologi, fitur yang sudah dibuat, struktur proyek, integrasi, status pekerjaan, dan langkah melanjutkan proyek di workspace baru.
4. Amankan informasi database dan deployment: Dokumentasikan konfigurasi MongoDB dan Railway yang diperlukan untuk pemulihan, tanpa membocorkan password, API key, atau rahasia lainnya. Jangan mengubah atau menghapus data produksi.
Prioritaskan pengumpulan source code dan pembuatan ZIP, kemudian buat rangkuman proyek.
Jangan mengarang kode atau mengklaim backup berhasil jika file belum benar-benar dibuat. Jika akses file atau fitur ekspor terkunci, jelaskan keterbatasannya dan berikan alternatif yang bisa dilakukan tanpa upgrade.
Di akhir, laporkan file yang berhasil dibuat, sertakan tautan unduhan yang benar-benar tersedia, dan jelaskan apa yang masih perlu dilakukan secara manual."
